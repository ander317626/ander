# 序知 / SIGNAL

黑白极简风格的 AI 资讯精选网页。

网站：https://ander317626.github.io/ander/

## 文件

- `index.html`：可独立打开的网页，包含搜索、机构筛选、本地收藏和 JSON 导出。
- `news.json`：本期 7 条资讯的结构化数据与来源链接。
- `.nojekyll`：让 GitHub Pages 直接提供静态文件。

## 内容与更新

本期信息核验日期为 2026-11-05，区分官方公告与媒体报道，并标注尚待补证的内容。当前为静态快照，没有自动采集或定时更新服务。

页面内嵌资讯数据以支持直接打开 HTML；更新资讯时需要同时更新 `index.html` 的 `news` 数据与 `news.json`。

## GitHub Pages

从 `main` 分支根目录发布。推送修改后由 GitHub Pages 自动重新部署。
